# Changelog

Краткие изменения по версиям. Ссылки на вошедшие pull request и участников GitHub добавляет
в [релизы](https://github.com/Horcag/sto-report-generator/releases) автоматически.

## 1.2.0

- Проектный навык для лабораторных, курсовых и НИР доступен после прямой локальной установки через npm и в папке нового отчёта. README отчёта показывает команды для установленного CLI и открывает материалы из того же пакета.
- В архив включена [база проверок русской учебной прозы](docs/case-studies/README.md). Два CSV содержат 61 завершённую подачу по 51 различному файлу. В базе описаны неудачные изменения, точные повторы и порядок добавления новых серий.
- `generate` и `audit` с движком `word` выполняют полную обработку через Microsoft Word на Windows, в том числе при запуске из WSL. Добавлены настройки качества PDF и времени обработки больших отчётов.
- Расширены проверки библиографических идентификаторов, версий наборов данных и записей, извлечённых из готового документа. Исправлена обработка ссылок на формулы и пустых операндов. Обновлён экспериментальный маршрут [Wordcraft 0.18.1](docs/wordcraft-compatibility.md).

## 1.1.0

- Добавлена публичная галерея из 29 страниц примеров с формулами, матрицами и элементами отчёта.
- Исправлена вёрстка математических выражений в DOCX с родными формулами Word.
- Добавлены правила LF для текстовых файлов и проверка исходных байтов Git и рабочей копии.
- Введены согласованные версии пакета и тегов, GitHub Releases с архивом CLI,
  автоматические заметки по merged pull request и публичный roadmap.

Публикация в npm registry в этот выпуск не входит. Экспериментальный Wordcraft renderer
сохраняет ограничения, указанные в [матрице совместимости](docs/wordcraft-compatibility.md).

## 1.0.0

Исходная версия пакета до введения регулярных GitHub Releases. Отдельный опубликованный
релиз для этой версии не создавался; полный перечень прежних изменений здесь не восстановлен.
