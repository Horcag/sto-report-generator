# Changelog

Краткие изменения по версиям. Ссылки на вошедшие pull request и участников GitHub добавляет
в [релизы](https://github.com/Horcag/sto-report-generator/releases) автоматически.

## 1.1.0

- Добавлена публичная галерея из 29 страниц примеров с формулами, матрицами и элементами отчёта.
- Исправлена вёрстка математических выражений в DOCX с родными формулами Word.
- Добавлены правила LF для текстовых файлов и проверка исходных байтов Git и рабочей копии.
- Введены согласованные версии пакета и тегов, GitHub Releases с архивом CLI,
  автоматические заметки по merged pull request и публичный roadmap.

Публикация в npm registry в этот выпуск не входит. Экспериментальный Wordcraft renderer
сохраняет ограничения, указанные в [матрице совместимости](docs/wordcraft-compatibility.md).

## 1.0.0

Исходная версия пакета до введения регулярных GitHub Releases. Отдельный опубликованный
релиз для этой версии не создавался; полный перечень прежних изменений здесь не восстановлен.
