# Roadmap

Направления развития, без обещанных дат. Выполненные изменения фиксируются в
[CHANGELOG](CHANGELOG.md) и [GitHub Releases](https://github.com/Horcag/sto-report-generator/releases).
Конкретные задачи и доказательства проверки остаются в [доске репозитория](kanban/tasks).

## Ближайшие направления

- Расширять проверочный корпус формул и таблиц по воспроизводимым примерам расхождений.
- Пополнять галерею проверенными страницами и сохранять связь изображений с исходниками,
  версиями генератора и результатами Word-приёмки.
- Закрывать оставшиеся пробелы СТО по [реестру требований](docs/sto-rules-coverage.md)
  и [аудиту](docs/audits/2026-09-22-sto-coverage/README.md).
- Проверять экспериментальный Wordcraft renderer на корпусе с подтверждённым происхождением
  и публиковать границы совместимости с Word.

## Требуют отдельного решения

- Публикация CLI в npm registry: сейчас установка поддерживается из архива GitHub Release.
- Графический интерфейс: сначала нужен подтверждённый пользовательский сценарий;
  см. [исследование интерфейса](docs/architecture/gui-discovery.md).
- Удалённый Microsoft renderer: требуется отдельное решение о передаче документов;
  см. [архитектурное исследование](docs/architecture/remote-microsoft-renderer.md).

Эти пункты обозначают планируемую работу. Наличие пункта в roadmap не подтверждает реализацию
или прохождение приёмки.
