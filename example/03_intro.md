\sto_structural_heading{ВВЕДЕНИЕ}

Настоящий документ автоматически сгенерирован с использованием `sto-report-generator`. Данный проект решает проблему рутинного ручного форматирования документов MS Word и позволяет использовать удобную разметку Markdown для подготовки курсовых, дипломов и отчетов по НИР [@petrov2024].

Основные возможности программы:
\begin{sto_enum}
1. Генерация титульного листа по заданным метаданным;
2. Автоматическое составление оглавления;
3. Поддержка списков, таблиц, формул ($LaTeX$);
4. Расстановка ссылок на рисунки и таблицы с проверкой Hanging References.
\end{sto_enum}
