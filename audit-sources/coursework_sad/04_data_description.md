# 1 Описание используемых данных

В работе используется региональная аналитическая панель, собранная из двух основных источников: выгрузки ФНС России по субъектам малого и среднего предпринимательства и кредитной статистики Банка России по МСП. Кредитные показатели Банка России уже заданы в территориальном разрезе, а данные ФНС сначала агрегируются по территориям. После сопоставления названий регионов обе таблицы объединяются в одну панель, где одно наблюдение соответствует одной территориальной единице.

Кредитная статистика относится к кредитам, предоставленным юридическим лицам и индивидуальным предпринимателям, по состоянию на 01.03.2026. Все денежные показатели Банка России выражены в миллионах рублей. Данные ФНС представлены рабочей выгрузкой из открытого реестра МСП, сформированной по срезу 10.03.2026 [@fns_rsmp; @cbr_msp_stats]. В анализе используется таблица на 50 000 строк ФНС: это значение задано параметром подготовки рабочей выгрузки и не означает, что в официальном реестре содержалось ровно 50 000 записей.

Данные ФНС используются как приближенное структурное описание доступного среза МСП: организационно-правовой тип, размер предприятия, основной код ОКВЭД и признак новой записи. Поэтому далее формулировки вида «доля ИП» или «доля микропредприятий» означают долю среди сопоставленных строк рабочей выгрузки ФНС, а не официальную долю всех субъектов МСП в регионе. Для контроля этого ограничения в анализе отдельно учитывается число строк ФНС, попавших в каждую территорию.

Роль двух исходных таблиц в формировании панели показана в таблице 1.

Таблица 1 – Исходные таблицы, участвующие в формировании панели

| Источник | Единица наблюдения | Роль в работе |
|---|---|---|
| Реестр МСП ФНС России | отдельная запись о субъекте МСП | используется для расчета структурных долей рабочей выгрузки по территориям |
| Статистика кредитования МСП Банка России | территориальная единица | используется для расчета задолженности, просрочки, месячных выдач и целевой переменной |

Дополнительно на этапе аудита проверялся файл макроопроса Банка России. В итоговую панель и статистические тесты он не включен, потому что в текущем виде представляет набор ячеек листов без явного регионального ключа. Поэтому ниже расшифровываются только те таблицы и столбцы, которые реально участвуют в построении аналитической панели.

## 1.1 Столбцы исходной таблицы ФНС

Расшифровка столбцов рабочей таблицы ФНС приведена в таблице 2.

Таблица 2 – Столбцы исходной таблицы ФНС

| Столбец | Смысл |
|---|---|
| `doc_id` | технический идентификатор записи в выгрузке |

| `msp_type` | тип субъекта МСП в исходной кодировке ФНС |
| `msp_category` | категория МСП: микро-, малое или среднее предприятие |
| `is_new_flag` | признак новой записи в реестре |

| `okved_main_name` | текстовое название основного вида деятельности |
