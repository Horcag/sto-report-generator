# WordCraft: совместимость с Microsoft Word

<!-- cspell:words Calibri SECTIONPAGES -->

Проверяемая версия: **0.9.0**, 21 октября 2026 года. WordCraft остаётся экспериментальным
PDF-движком. Он уже позволяет собрать и просмотреть отчёт без Word, но пока не обеспечивает
одинаковую с Word вёрстку. Для документа, который должен выглядеть именно как экспорт Word,
финальный этап с Word ещё нужен.

## Что именно сравниваем

Генератор создаёт DOCX: стили СТО, формулы OMML, рисунки, таблицы, ссылки и библиографию.
WordCraft получает этот DOCX и строит PDF. Обновление движка само по себе не добавляет
поддержку новых конструкций Markdown и не исправляет ошибки исходного текста.

Для сравнения использованы одинаковые исходные DOCX, обновление полей и независимое чтение
PDF. Основной контроль шрифтов включает Times New Roman со всеми начертаниями, Cambria Math,
Arial, Calibri и Courier New. Отдельный запуск без этих файлов показывает влияние подстановки.
Word выполняет наш обычный этап приёмки: обновляет поля, подгоняет таблицы, разделяет длинные
таблицы и повторно открывает сохранённый документ. Поэтому сравнивается результат доступных
пользователю процессов, включая доработки нашего Word-процесса, а не только два алгоритма отрисовки.

Исходники личных работ и их PDF не публикуются. В открытом аудите приведены только
обезличенные результаты и контрольные суммы; публичные примеры можно воспроизвести.

На публичном контроле формул видны различия даже с одинаковыми шрифтами: в WordCraft
дробь мельче, отличаются интервалы и положение пределов операторов. Оглавление начинается
ниже и имеет другой отступ слева. На второй странице длинной таблицы Word добавляет
«Продолжение таблицы 1», а WordCraft повторяет шапку без этой надписи; помещается другое
число строк. Первые два расхождения относятся к вёрстке движка, последнее также показывает
отсутствие нашего Word-этапа разделения таблиц в экспериментальном процессе.

## Платформы

| Среда                                     | Уровень подтверждения                                                                                 | Практический вывод                                                               |
| ----------------------------------------- | ----------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| Linux CLI в WSL, x86-64                   | Реально выполнены экспорт и сравнение с Word, с подстановкой шрифтов и с контрольными файлами шрифтов | Можно использовать для экспериментального PDF; идентичность Word не подтверждена |
| Обычный Linux                             | Выпускается тот же Linux CLI; отдельный физический Linux-хост не проверялся                           | Ожидается тот же класс ограничений; отдельно обеспечить шрифты и зависимости     |
| Windows, x64 CLI                          | Реально выполнен экспорт публичных и личных контролей                                                 | Наличие Word на машине не делает экспорт WordCraft экспортом Word                |
| macOS, universal CLI                      | Официальный архив существует; запуска на Mac в этом аудите нет                                        | Совместимость по вёрстке не измерена; общий движок не заменяет проверку на Mac   |
| Linux ARM64 / RISC-V, Windows ARM64 / x86 | Официальные пакеты существуют; исполнения в этом аудите нет                                           | Нельзя переносить результаты x86-64 как доказанную приёмку этих сборок           |

WSL запускает Linux-сборку WordCraft. Сравнение с Word в WSL возможно через установленный
Windows Word и `accept:word`; обычному Linux или Mac этот маршрут сам по себе недоступен.
Файлы шрифтов Windows не распространяются вместе с генератором.

## Что изменилось в 0.9.0

Для нас полезны исправления импорта формул [#2613](https://github.com/storytold/wordcraft/pull/2613),
базовой линии возле высоких формул [#2435](https://github.com/storytold/wordcraft/pull/2435),
обновления оглавления [#2553](https://github.com/storytold/wordcraft/pull/2553),
отступов таблиц на продолжении [#2524](https://github.com/storytold/wordcraft/pull/2524),
переноса строк таблицы [#2925](https://github.com/storytold/wordcraft/pull/2925)
и распознавания встроенных шрифтов [#2540](https://github.com/storytold/wordcraft/pull/2540).

Новый `convert --update-fields` вызывает уже существующий механизм обновления полей.
Наша интеграция вызывала его явно и раньше; это не новая возможность для наших отчётов.
Изменения ленты, диалогов и буфера обмена настольного WordCraft не следует считать
улучшениями CLI-экспорта.

Upstream отдельно указывает на неполную совместимость пагинации и параметров математической
вёрстки: [layout parity](https://github.com/storytold/wordcraft/blob/v0.9.0/docs/layout-parity.md),
[file format parity](https://github.com/storytold/wordcraft/blob/v0.9.0/docs/file-format-parity.md).
В частности, `m:mathFont` игнорируется и запрашивается Cambria Math; часть математических
параметров по умолчанию не учитывается. Исторические проценты совместимости из документации
upstream не являются результатом проверки наших документов.

## Что нужно доработать в генераторе

Ближайшие задачи следуют из измеренных расхождений:

1. Перенести подписи продолжений и разделение длинных таблиц из Word-автоматизации в
   переносимый этап; затем повторить проверку всех строк и страниц таблиц.
2. Добавить проверку наличия и фактической подстановки шрифтов перед экспортом. Сейчас
   пользователь может получить PDF с другими шрифтами без отдельной ошибки о подстановке.
3. Закрепить сравнения оглавления и формул как повторяемый набор для каждого обновления
   движка. Исправление размеров формул и метрик относится прежде всего к upstream; правка
   отступов в одном отчёте не докажет исправление всех документов.
4. Дополнить корпус многосекционными шаблонами и выполнить сравнение на Mac. Эти сценарии
   остаются непроверенными.

Это список дальнейших работ, а не функции, выполненные этим обновлением. Пока надёжный
путь к оформлению Word — финальный экспорт через Word; редактировать готовый PDF для
устранения систематических расхождений не следует.

## Когда можно отказаться от Word

Для чернового просмотра и PDF, где допустима самостоятельная вёрстка WordCraft, движок уже
пригоден после проверки формул, таблиц и страниц. Если нужна идентичность утверждённому
шаблону Word, оснований убирать Word пока нет.

Для изменения этого решения нужен устойчивый набор сравнений: оба шаблона генератора,
большие отчёты, формулы, длинные таблицы, приложения и многосекционные документы. После
каждого обновления фиксируются версии, шрифты и хеши входов; независимо проверяются PDF,
содержимое и расположение объектов. Известные расхождения должны исчезнуть либо получить
явно согласованный допуск. Равенство числа страниц или успешная проверка XML этого не заменяют.
