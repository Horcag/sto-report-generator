# Проверка управления рисунками

Проверена реализация `5665e57e6aab85858ea54bcc8f8beb2037e0d97b`. Изменение добавляет настройки отдельного вхождения рисунка в `figures.json`, инспектор реальных изображений и
проверку сохранения рисунков после открытия и сохранения в Word. Ширина задаётся в миллиметрах; обрезка остаётся
редактируемой в Word. DPI и размер текста оцениваются отдельно. Исходные изображения не уменьшаются при сборке.

## Проверка в установленном Word

Проверен синтетический отчёт с пятью рисунками: PNG в двух размерах, обрезанный PNG, SVG с настоящим PNG-резервом
и маленькая растровая иконка. Приёмка выполнена штатным `npm run accept:word` в Word 16.0.20430. Сохранённый DOCX
повторно открыт, PDF экспортирован; результат `accepted`, `processCleanupVerified=true`.

Все пять размеров и параметры обрезки сохранились. Байты обычных PNG и исходного SVG совпали до и после Word.
Word создал новый PNG-резерв SVG: 2400 × 1200 вместо 1800 × 900. Проверка допускает это только при неизменном
SVG, полноценном декодировании PNG, сохранении пропорций и отсутствии уменьшения пикселей или DPI по каждой оси.
Повреждённые PNG, изменение первичного растра, исходного SVG, геометрии или удаление защиты от сжатия отклоняются.

| Рисунок        | Ширина DOCX |               DPI растра в DOCX | Результат в PDF           |
| -------------- | ----------: | ------------------------------: | ------------------------- |
| PNG            |      140 мм |                          326,57 | 1102 × 551, около 200 DPI |
| Тот же PNG     |      100 мм |                          457,20 | 1102 × 551, около 280 DPI |
| Обрезанный PNG |      130 мм | 337,62 с учётом видимой области | 1023 × 373, около 200 DPI |
| SVG            |      140 мм |       резерв: 435,43 после Word | векторная графика         |
| Иконка         |       10 мм |                          243,84 | 96 × 96, около 244 DPI    |

Измерения выполнены по растрам и их размещению внутри конечного PDF через PyMuPDF. Просмотрены все три страницы:
подписи и элементы тестовых схем видны, обрезка не удаляет текст, рисунки остаются рядом со своими подписями.
SHA-256 PDF: `e4365a9bd954b22d5b8edb541afb496da6600767086b57ee737fcd1f75afdc62`.

Экспорт запрашивает `ExportAsFixedFormat2` с `OptimizeForImageQuality=true`, однако этот Word всё равно уменьшил
растры в PDF. Поэтому диагностика экспорта сохраняет `qualityStatus=unverifiedUntilPdfInspection`; флаг не считается
доказательством исходного разрешения. Старый API используется только при отсутствии нового метода и выдаёт явное
предупреждение. Ошибка экспорта не запускает скрытый переход к старому режиму.

## Проверка инспектора

В настоящем браузере проверены пять встроенных изображений, изменение ширины, обрезки и измеренного размера текста,
предупреждения и содержимое скачанного JSON. Некорректные ширина и обрезка блокируют выгрузку. На ширинах 1280 и
390 пикселей нет горизонтального переполнения. Нет ошибок консоли и внешних запросов скриптов, стилей или данных.

Регрессионные проверки включают 39 случаев сохранности рисунков, шесть случаев вызова PDF API без запуска Word,
контроль DPI после обрезки, мелкий текст при высоком DPI, настоящие и повреждённые PNG, повторные вхождения,
переносимость путей, восстановление настроек и браузерные изменения. Общие проверки проекта выполняются отдельно
от native Word и визуальной приёмки.

На проверенной реализации прошли все 29 TypeScript-наборов, 28 Python-проверок политики, форматирование, ESLint,
TypeScript, FSD, проверка состава пакета, размеров файлов, ссылок и орфографии. Покрытие: строки 89,65%, функции
96,82%, ветви 82,90%; действующие пороги не снижались. Отдельно прошли Ruff и mypy для 22 файлов Python.

Полный `npm run quality` завершился ошибкой на последнем `npm audit`: десять прежних находок, включая зависимости
`braces`, `source-map-js` и `sprintf-js`. Манифесты зависимостей и lock-файл этим изменением не менялись. Для
`source-map-js` существует исправление, но остальные цепочки не устраняются предложенными принудительными
понижениями без отдельной проверки совместимости. Gate безопасности остаётся включённым; успешные функциональные
проверки не объявляются прохождением всего gate.

## Воспроизведение

```sh
uv run --no-project --with pillow python tests/quality/render_figure_fixture.py /path/to/fixture
npx tsx src/index.ts build /path/to/fixture /path/to/raw.docx
npx tsx src/index.ts figures preview /path/to/fixture --output /path/to/figures.html
npm run accept:word -- /path/to/raw.docx --accepted-docx /path/to/accepted.docx --pdf /path/to/accepted.pdf --manifest /path/to/acceptance.json
```

Инструкция пользователя: [управление рисунками](../figure-controls.md). Параметр экспорта описан в
[Microsoft Learn](https://learn.microsoft.com/en-us/office/vba/api/word.document.exportasfixedformat2).
