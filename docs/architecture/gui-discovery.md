# GUI discovery

Проверено 24 сентября 2026 года. Доступный сигнал спроса ограничен: в репозитории на GitHub обнаружена одна issue, посвящённая именам стилей Word, без запроса на графический интерфейс. README описывает запуск через CLI и агентные сценарии. Опросов пользователей без агента и наблюдений их работы нет, поэтому отсутствие такого спроса не доказано.

Текущая граница продукта — команды `new`, `check`, `generate`, `audit` и `accept-word` с явными путями и диагностикой. Для проверяемого GUI-сценария сначала нужен повторяющийся пользовательский запрос: кто создаёт отчёт без терминала, какие операции он выполняет и где CLI мешает завершить работу. Критерий возврата к разработке — несколько независимых сценариев работы без агента с наблюдаемой потерей времени или ошибками в CLI.

Если такой спрос появится, первая реализация — локальная web-оболочка поверх существующего CLI/API с выбором каталога, профиля, preview и ссылкой на диагностические сообщения. Она должна наследовать ограничения процессов Word и не обходить проверку документа. Electron потребует отдельного доказательства, что системного браузера и локальной оболочки недостаточно; сейчас такого доказательства нет.

Итог discovery: GUI не добавлять в текущий перенос СТО; проверять спрос по новым issue и реальным попыткам пользователей без агента, не превращая предположение в обязательную функцию.
