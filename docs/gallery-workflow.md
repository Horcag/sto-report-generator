# Обновление галереи

[Галерея](gallery.md) содержит все страницы пяти публичных документов. README показывает несколько страниц
и ведёт в полный индекс. Тестовые исходники используются без отдельной редактируемой копии для документации.
Одиночные тесты формул и матриц получают демонстрационные титульные данные из `example/00_metadata.md`;
тело теста сохраняется без изменений. Для корпуса стилей используется каноническая пара
`example/images/dummy.svg` и `dummy.png`, как в проверке Wordcraft.
Длинная таблица того же корпуса расширяется до 90 строк тем же способом, что в живом регрессионном тесте,
чтобы в галерее было видно её продолжение на следующих страницах.

## Пересоздание

Из корня клонированного репозитория, на Windows с установленными Microsoft Word и Times New Roman либо из WSL с доступом к этому Word:

```bash
npm ci
npm run gallery:update
npm run gallery:check
```

Команда собирает каждый DOCX текущим генератором и запускает `npm run accept:word -- <docx>`.
Штатный launcher ограничивает время работы Word, проверяет завершение созданных процессов,
обновляет поля и оглавление и сверяет число страниц после повторного открытия.
Для корпуса с SVG-иллюстрациями явно используется `--pdf-image-quality print`.
Для корпуса формул автоматически проверяется расположение всех 14 номеров в PDF.
Каждая страница принятого PDF сохраняется в PNG с разрешением 120 DPI через PyMuPDF.
Только после успешной обработки всего корпуса обновляются картинки, индекс и манифест.
Промежуточные документы и локальные receipts автоматически удаляются, включая случай ошибки.

Команда использует временный рабочий каталог и автоматически удаляет промежуточные файлы. В Git попадают только PNG и публичный манифест;
временные DOCX и PDF не нужны для просмотра галереи.

## Проверка актуальности

```bash
npm run gallery:check
```

Проверка работает на Linux, macOS и Windows без Microsoft Word и PyMuPDF. Она сравнивает SHA-256 кода генератора,
Word pipeline, зависимостей и исходников корпуса, с приведением переводов строк текстовых входов к LF, затем проверяет точный хеш каждого PNG и полный список страниц в индексе.
Смена версии пакета также требует обновления галереи. В манифесте нет абсолютных локальных путей и текущего времени,
поэтому обычная проверка не создаёт изменений.

Команда входит в `npm run ci:check`, а через `npm run quality` — в workflow сборки выпуска.
Если входные файлы изменились, CI блокируется до выполнения `npm run gallery:update` и включения результата в коммит.
Автоматическая проверка на hosted runner не требует доступа к Word; само обновление выполняется там, где Word установлен.

## Что показывает корпус

- `example/`: демонстрационный отчёт со стандартными разделами, списками, таблицей и рисунком.
- `tests/fixtures/formulas/layout.md`: номера и переносы формул, дроби, системы, интегралы и кусочные функции.
- `tests/fixtures/formulas/fences.md`: единичные матрицы и скобки вокруг дробей для визуального сравнения.
- `tests/fixtures/wordcraft/matrix-controls.md`: размеры матриц, скобки, определители и вложенные конструкции.
- `tests/fixtures/dotm-word-corpus/`: уровни заголовков, оглавление, рисунок, длинная таблица и библиография.

Это синтетические примеры возможностей и регрессионные проверки отдельных конструкций.
Изображения не подтверждают соответствие любого отчёта всем требованиям СТО.
Новые документы добавляют в явный список `CORPUS` в `scripts/quality/report_gallery.py` после проверки публичности содержимого.
