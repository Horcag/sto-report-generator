# Публичная инвентаризация источников

Этот файл отделяет публично безопасные материалы проекта от частных отчетов, локальных загрузок и переписок. Его можно
использовать как источник для README, issue и release notes.

## Версионируемая документация покрытия СТО

Класс происхождения: документация репозитория.

- `docs/sto-rules-coverage.md` описывает, какие правила СТО уже покрыты source preflight, DOCX validation и post-build.
- `docs/report-authoring.md` фиксирует публичные правила для Markdown-отчетов.
- `docs/architecture/python-post-build.md` описывает устройство Python post-build пакета.

Эти файлы не должны содержать частный текст отчетов, идентификаторы мессенджеров, пользовательские имена, локальные пути
загрузок или закрытые ссылки.

## Версионируемый DOTM fixture

Класс происхождения: репозиторный fixture, извлеченный из шаблона Самарского университета.

- `tests/fixtures/validator/etalon/SHablon_oformlenija_VKR_2022_5_6.dotm` используется для сравнения OpenXML стилей.
- `tests/fixtures/validator/etalon/dotm-style-contract.json` фиксирует SHA-256 fixture, инвентарь всех 79 style ID,
  их display names, семантический отпечаток без служебных revision-метаданных и статус переноса (`mapped`, `adapted`, `deferred`
  или `ignored`). Проверка выполняется в переносимом CI без Word.
- `docs/architecture/dotm-template-style-audit.md` содержит безопасную сводку параметров из `word/styles.xml` и
  `word/numbering.xml`.

Acquisition evidence: файл, загруженный из LMS, `template_vkr_2022_5_6_1_9778.dotm` имеет SHA-256
`869c0bea96ce2f6ece4d42a36adf2657e997ad23c627a6cd5760e97638702146`. Он не совпадает с tracked fixture побайтово,
но все 79 style definitions дают тот же нормализованный semantic SHA-256
`0c3050bd4c548273f4f530822e08f64764775b25d97139ecf158cf0f80e2c820`. Закрытый URL курса и локальные пути намеренно
не публикуются. Ни один из двух файлов не содержит `vbaProject.bin`, несмотря на расширение `.dotm`.

Генератор не зависит от макросов DOTM. Штатный preset `samara-template-2022` переносит точные display names для
сопоставленных генераторных стилей, но не повторяет DOTM style ID и не заявляет полную побитовую идентичность
форматирования. `stylePreset: "default"` оставлен только как
явный режим совместимости со старыми нейтральными именами.

## Внешние методические материалы преподавателя

Класс происхождения: пересказанные внешние методические материалы.

Публично безопасные факты:

- преподаватель показывает работу со стилями шаблона, а не отдельный новый стандарт форматирования;
- основной текст использует Times New Roman 14 pt, полуторный интервал, выравнивание по ширине и отступ первой строки
  1.25 cm;
- рисунки должны быть inline/in-text, без floating/anchored размещения;
- для рисунков и подписей используются отдельные стили, которые желательно держать рядом;
- во время ручной проверки полезно включать непечатаемые символы;
- альтернативные редакторы могут сохранять стили, но здесь не доказана идентичная Word-пагинация.

Не публикуйте исходные внешние ссылки, идентификаторы мессенджеров, пользовательские имена, локальные пути загрузок,
страницы частных отчетов или закрытые скриншоты.

## Происхождение preview-изображений

В README встроены два безопасных preview-изображения:

- `docs/assets/example-page-1.png`
- `docs/assets/example-page-5.png`

Они сгенерированы из демонстрационного отчета `example/` и содержат только демонстрационные имена и placeholder-содержание.
Исходный PDF не считается tracked source; проверяемым источником остается tracked Markdown/DOCX pipeline для `example/`.

Renderer-agnostic воспроизводимый шаг для подготовки DOCX:

```bash
npm run audit:report -- example --renderer portable
```

Дальше откройте полученный DOCX в выбранном локальном просмотрщике и экспортируйте нужные страницы в PNG. Для публичного
preview допустимы только страницы демонстрационного отчета `example/`; частные отчеты, закрытые скриншоты и локальные пути
загрузок запрещены.
